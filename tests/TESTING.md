# 催化智构 CataMind · 测试手册（TESTING GUIDE）

> 面向局域网部署的催化材料智能计算平台 —— 分模块功能测试与验收标准。
> 测试文件位于 `tests/` 目录，与平台同目录下的 `server.py`、`index.html` 配合使用。

---

## 0. 测试环境准备

```bash
# 1. 启动后端（若未运行）
cd catmat-platform
python3 catmat.py serve --port 8000 --host 0.0.0.0

# 2. 浏览器打开
http://127.0.0.1:8000   # 本机
http://<服务器IP>:8000   # 局域网其他电脑（需放行防火墙 8000/tcp）

# 3. 确认依赖（左下角版本号面板应全绿）
#    CP2K 2026.2 / AiiDA 2.8.0 / Multiwfn / scikit-learn / shap / xgboost / ASE / numpy
```

**注意**：OT 生成、结构生成、PDOS 后处理、ML 训练依赖服务器真实安装的 Multiwfn / ASE / AiiDA 环境。若某项未安装，对应测试会提示错误。

## 3. CP2K 输入推荐模块（含 OT）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 3.1 | 点「输入推荐」 | 推荐卡展示泛函/截断/k 点/色散/基组 + **OT 相关推荐卡**（SCF 方法/预处理器/最小化器/线搜索/外层 SCF） |
| 3.2 | 观察可编辑输入块默认内容 | 展示 Multiwfn 实际生成的「Si 块体 + GEO_OPT + OT」输入文件（含 `&OT`/`&OUTER_SCF`/`&GEO_OPT`），无 `&MIXING`/`&SMEAR` |
| 3.3 | 点「校验」看徽标 | 「✓ 全部关键词合法」 |
| 3.4 | SCF 方法选「OT」，结构来源选「内置 Si 块体」，点「生成 .inp」 | 生成 OT 输入文件，含 `&OT`/`PRECONDITIONER`/`MINIMIZER`/`LINESEARCH`/`ALGORITHM` |
| 3.5 | SCF 方法选「Diagonalization」，Smearing 勾选，点「生成 .inp」 | 生成对角化输入文件，含 `&DIAGONALIZATION`/`&MIXING`/`&SMEAR` |
| 3.6 | 点「Vim 语法高亮」 | 下载 `cp2k.vim` 文件 |
| 3.7 | 点「Vim 工具说明」 | 弹窗展示安装命令与快捷键 |

### 3.8 OT 与对角化冲突校验（重点）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| a | 把 `tests/test_ot.inp` 内容粘贴进输入块 | 徽标「✓ 全部关键词合法」 |
| b | 把 `tests/test_diag.inp` 内容粘贴进输入块 | 徽标「✓ 全部关键词合法」 |
| c | 把 `tests/test_conflict.inp` 内容粘贴进输入块 | 徽标显示**错误 + 警告**：①「&OT 与 &DIAGONALIZATION 互斥」（红）；②「&MIXING 仅用于对角化」（黄）；③「&SMEAR 不支持 OT」（红） |

**验收标准**：合法输入（OT 或对角化单独出现）零告警；冲突输入能报出 3 类互斥问题。

## 附：已知边界与说明

1. **计算节点真实提交**：工作流的 scf/geo_opt/pdos 节点当前为「入队到任务表」状态；接入真实 `verdi run` 提交需对接具体 WorkChain 脚本（structure/inp 节点是真实执行的）。
2. **大模型功能**：对话助手与 AI 生成 INP 需在右下角 ⚙ 配置 OpenAI 兼容 API（DeepSeek/通义等）后方可联网检索与推理。
3. **OT 适用性**：OT 适用于非金属带隙体系；金属体系请用对角化 + smearing。
