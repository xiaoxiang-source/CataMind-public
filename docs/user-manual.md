## 1. 术语表

| 术语 | 含义 |
|---|---|
| **体系** | 一个材料结构（如某个 IrRuO 表面模型）及其信息，保存在「研究体系」中 |
| **结构** | 原子的三维排布（元素种类、坐标、晶胞） |
| **描述符** | 描述材料特征的数值指标，如 d 带中心（ε_d）、过电位（η_OER）、功函数 |
| **η_OER** | 析氧反应过电位，衡量催化剂活性的关键指标（数值越小通常越好） |
| **ε_d（d 带中心）** | 由 PDOS 计算得到的电子结构描述符，常与催化活性关联 |
| **INP / .inp** | CP2K 计算输入文件 |
| **GEO_OPT** | 几何优化（结构优化）计算：让原子位置弛豫到能量较低的状态 |
| **单点能 / ENERGY** | 只对给定结构算一次能量，不改变结构 |
| **PDOS** | 投影态密度；平台通过解析它得到 d 带中心等描述符 |
| **Bader 电荷** | 一种原子电荷划分方法，用于分析电荷转移 |
| **工作流** | 把多个计算步骤串起来自动执行（如：结构优化 → 单点能 → 后处理） |
| **批次** | 高通量筛选中一次批量提交的一组结构 |
| **训练** | 用已有数据拟合机器学习模型，用于预测新材料的性能 |
| **主动学习** | 让模型在预测的同时给出不确定性，据此推荐"最值得算"的下一批结构 |
| **休go** | 平台内置的 AI 助手（昵称小休、小go），可对话并跨平台模块执行操作 |

## 2. 开始之前：访问与界面

### 2.1 访问平台

1. 在浏览器地址栏输入平台网址（由课题组东翁 / 掌书提供）。
2. 输入东翁（或获授权的掌书）创建的本地用户名和密码，点击「登录」。
3. 登录成功后，右上角身份卡会显示「个人名称 / 身份」（如 博士 / 东翁）；点击身份卡打开「账号与平台」菜单，可查看账号信息、关于平台，或注销登录。

> 📷 截图占位：`screenshots/01-login-home.png`（建议：账号密码登录页与登录后的身份标识）

### 2.2 关于账号与身份（请务必了解）

平台身份分三类（身份词仅用于说明权限，账号显示一律用个人名称）：

| 身份 | 定位 | 权限 |
|---|---|---|
| **东翁** | 唯一超级管理员（平台所有者） | 全部权限：账号与身份管理、模型配置与密钥管理、删除数据、批量 ML/主动学习/高通量、任务终止、全局同步等，不设限 |
| **掌书** | 一般管理员（东翁授予） | 在东翁授予的**能力包**范围内代行事务（如数据维护 / 删除 / 账号管理 / 任务运行 / 批量流水线等）；未授能力默认只读 |
| **清客** | 普通用户 | 可查询平台数据、扩充文献库、AI 解读归档、提交与撤销**自己**的 CM- 计算队列任务；不能删除平台数据、管理账号或模型配置、执行批量 ML/主动学习/高通量操作，也不能暂停/取消/终止他人任务 |

- 账号和密码凭据仅保存在平台服务器的 SQLite 数据库中；**大模型 API 密钥由「平台设置 → 大模型」集中管理**（东翁或获授权掌书可读写），不依赖环境变量。
- 任务、工作流、HTS 批次、ML/AL 训练均记录**发起人**（账号个人名称），列表中以「· 发起：〈名称〉」显示。
- 界面上暂无个人文件隔离概念：平台业务数据由课题组共享，重要数据请定期导出留存（见[第 13 章](#13-数据导入导出速查)）。

## 3. 场景一：管理材料体系

**适用**：整理和保存你关心的催化剂结构，为后续计算与建模提供数据来源。

**页面路径**：左侧导航 → **研究数据** → **研究体系**

> 📷 截图占位：`screenshots/03-systems-list.png`（建议：体系列表 + 目录树）

### 3.1 新增体系（三种方式）

**操作步骤**

1. 点击右上角 **「＋ 添加 / 导入体系」**。
2. 在弹出的窗口中，按需选择三种方式之一：
   - **手动填写**：录入名称、化学式、晶格参数、描述符等字段。
   - **结构文件导入**：上传已有结构文件（支持 `.cif`、`.xyz`、`.gjf`、`.pdb`、`.mol`、`.vasp` 等常见格式），系统自动解析出组成、原子数与晶胞，并**按内容去重**。
   - **JSON 批量**：一次性导入多条体系记录。
3. 填写或选择完毕后确认保存。
4. 新体系出现在列表中，**最新保存的排在最前面**。

**预期结果**：体系出现在列表，包含名称、化学式与结构信息，可直接用于生成输入文件或启动计算。

**常见问题**

- *导入后没看到新体系？* 内容重复的条目会被自动去重，请检查列表中是否已有相同结构。
- *分子结构导入后晶胞异常？* 对于没有晶胞的分子，系统会自动用一个足够大的盒子包裹，属正常处理。

### 3.2 用目录归类体系

**操作步骤**

1. 在体系列表中，将某个体系**拖动**到左侧目录树的某个目录下即可归类。
2. 也可以拖动整个目录到另一个目录（支持多级目录，如"初始结构 / 金属 / Pt"）。
3. 选中若干体系后，点击 **「🗂 归档结构」** 可批量归档到指定目录。

**提示**：把目录拖到它自己或它的子目录下是不允许的，界面会给出提示。

### 3.3 查看体系结构与描述符

**操作步骤**：在列表中点击某个体系，可查看其三维结构预览与已有描述符（如 d 带中心、η_OER、功函数等）。

## 4. 场景二：构建与调整原子结构

**适用**：从零搭建表面模型、合金、掺杂或吸附构型，并导出结构文件。

**页面路径**：左侧导航 → **计算流程** → **结构生成**（页面标题：ASE 结构生成）

> 📷 截图占位：`screenshots/04-builder.png`（建议：参数区 + 右侧 3D 预览）

### 4.1 生成结构

**操作步骤**

1. 设置结构参数：
   - **元素**：从元素周期表中点选（覆盖前六周期 86 种元素），选中后自动填充常用晶格常数。
   - **晶面 / 层数 / 超胞 / 真空层**：按需要填写。
   - **合金比例、掺杂**：设置掺杂元素与比例。
   - **吸附**：选择吸附物种（如 OH、O、OOH、H₂O）与吸附位点（ontop / bridge / fcc / hcp / center）。
2. 点击 **「生成结构」**。
3. 在右侧三维预览中查看结果；可用鼠标旋转、缩放。
4. 需要微调时，先切换模式再点击结构上的原子：
   - **「选掺杂原子」**：点击结构中的原子指定掺杂位置。
   - **「放吸附分子」**：点击结构表面指定吸附位置。
5. 确认无误后：
   - 点 **「保存到体系列表」** —— 可自定义名称与保存目录，保存后进入「研究体系」；
   - 或点 **「下载 .xyz」** / **「下载 .cif」** 直接导出文件。

**预期结果**：三维预览显示符合参数的原子结构；保存或导出成功。

**重要提示**：结构**只有在你点击"保存到体系列表"时才会写入数据库**；生成、预览、调参过程不会产生任何记录，可以放心反复尝试。

**常见问题**

- *吸附分子位置不对 / 跑到边缘？* 系统默认把吸附物种放在表面中心的高对称位点（fcc hollow）以避免边界问题；如需指定，用「放吸附分子」模式点击目标位置。

## 5. 场景三：生成与校验计算输入文件

**适用**：为 CP2K 计算生成可用的 `.inp` 输入文件，并核对参数。

**页面路径**：左侧导航 → **计算流程** → **输入推荐**（页面标题：CP2K 输入推荐）

> 📷 截图占位：`screenshots/05-input-recommend.png`（建议：参数表单 + 生成的 INP + 校验结果）

### 5.1 生成 .inp

**操作步骤**

1. 选择**结构来源**：可从「研究体系」中选择已保存的结构（点 **「导入结构」**），或使用默认示例结构。
2. 设置计算参数：
   - **计算类型**：Energy / Energy+force / GEO_OPT / CELL_OPT / 振动 / MD / BAND（共 7 种）
   - **SCF 求解方法**：`Diagonalization`（对角化，金属与带隙体系均适用）或 `OT`（轨道变换，非金属带隙体系推荐，收敛快，不支持 smearing）
   - **色散校正**：无 / D3 / D3(BJ) / D4 / rVV10
   - **Smearing**：按需开启
3. （可选）点 **「＋ 添加参数行」** 添加更多参数：理论方法（PBE / PBEsol / PBE0 / HSE06 / B3LYP…）、基组与赝势（DZVP / TZVP / TZV2P / pob…）、密度混合、k 点网格、SCCS 溶剂化、TDDFT。未填写的按默认值处理。
4. （可选）在「基组文件名」「赝势文件名」下拉中切换基组/赝势；切换后系统会自动更新文件中各元素的对应设置。
5. 点击 **「⚡ 生成 .inp」**。
6. 查看生成结果；可用 **「缩进格式化」** 整理排版，用 **「Vim 语法高亮」** 辅助阅读（点 **「Vim 工具说明」** 查看安装方法）。
7. 确认后点 **「下载 .inp」** 保存；或点 **「存为知识条目」** 把该配置存入「CP2K 知识库」备查。
8. 需要重新填写时点 **「重置」**。

**预期结果**：生成包含相应 `RUN_TYPE`（如 GEO_OPT）的完整输入文件，可直接用于提交计算。

**常见问题**

- *想给不同元素设置不同参数？* 使用 **「按元素逐个设置」**（与「统一设置」互斥切换）。
- *生成时报参数错误？* 界面会提示具体问题行并高亮，按提示修改即可。

### 5.2 查询与核对参数含义

**页面路径**：左侧导航 → **计算流程** → **全参数设置**（页面标题：全参数设置）

**操作步骤**

1. 在左侧的参数规范树中逐级展开，找到目标 SECTION（如 `&DFT` → `&SCF`）。
2. 点击关键词查看其**官方英文描述、默认值、数据类型、取值枚举与所属路径**。
3. 也可用顶部搜索框直接检索关键词（如 `CUTOFF`），检索响应很快。
4. 需要时点 **「导入结构」** 结合具体体系查看，或 **「下载 .inp」** 导出、**「重置」** 复原。

**说明**：该模块收录 CP2K 官方输入规范的全部条目（数万条关键词与近万条 SECTION），并可从官方测试示例中反查某个关键词的用法。

## 6. 场景四：提交计算并监控进度

**适用**：把输入文件提交到计算环境执行，并跟踪运行状态。

**页面路径**：左侧导航 → **计算流程** → **计算任务**（页面标题：计算任务 CP2K Tasks）

> 📷 截图占位：`screenshots/06-tasks.png`（建议：进程树 + 已提交任务列表 + 停止按钮）

### 6.1 提交独立计算任务

**操作步骤**

1. 点击 **「提交独立 CP2K 任务」**。
2. 选择已准备好的输入文件，设置计算参数（进程数、线程数、输入/输出目录等）。
3. 确认提交。
4. 任务出现在「本平台已提交任务」列表中，并带有 **■ 停止** 按钮。

### 6.2 监控进度

**操作步骤**

1. 页面会**自动定时刷新**进程状态；也可点 **「↻ 刷新」** 立即更新。
2. 查看内容：
   - **进程树**：活跃计算的父子层级、当前步骤、状态与耗时。
   - **已提交任务**：状态（排队 / 运行 / 完成 / 失败）、所用资源。
3. 按编号（PK）精确定位某个计算：在输入框中填入编号后点 **「检索」**。

**预期结果**：任务状态随计算推进自动更新；完成或失败时会给出结果或错误信息。

### 6.3 停止任务

**操作步骤**：在对应任务或进程条目上点击停止按钮，确认即可。

**说明**：停止后任务状态更新为"已取消"。**无法中途暂停后继续**——如需重跑，请重新提交。

**常见问题**

- *状态一直不更新？* 点「↻ 刷新」手动同步；若长时间无变化，请联系东翁 / 掌书查看计算环境。
- *任务显示失败？* 将鼠标悬停或点击任务查看错误摘要（如输入错误、资源不足、SCF 不收敛），修正后重新提交。

## 7. 场景五：批量高通量筛选

**适用**：一次性对几十上百个候选结构跑完整的计算流程，并回收结果。

**页面路径**：左侧导航 → **计算流程** → **高通量筛选**（页面标题：高通量筛选 HTS）

> 📷 截图占位：`screenshots/07-hts.png`（建议：批次列表 + 启动工作流弹窗）

### 7.1 启动批量工作流

**操作步骤**

1. 点击 **「＋ 启动工作流」**。
2. 在弹窗中依次填写：
   - **基本信息**：工作流名称、选择参与计算的结构（可批量生成或从体系库中挑选）。
   - **结构优化设置**：该阶段参数已按课题组基线固化，界面会提示"不建议修改，除非你知道自己在做什么"。
   - **单点能设置**：同上，可勾选需要的输出项（PDOS、Bader 电荷密度、d 带中心等）。
   - **文件存放目录**：输入文件与输出文件的存放位置。
   - **计算资源及确认**：进程数、预计耗时等。
3. 需要时点 **「预览 Aiida 输入文件」**：系统会分别显示**结构优化**与**单点能**两个输入文件的内容（两个独立文本框），可分别选中文本框后做关键词的**替换 / 增加 / 删减**。
4. 选择**执行模式**（重要）：
   - **A · 逐结构链式（默认推荐）**：每个结构依次完成"优化 → 单点能 → 后处理"再进入下一个。总耗时最短、单个结构失败不影响其他结构。
   - **B · 波前并行**：先把所有结构优化完，再统一做单点能。优势是可在两阶段之间插入**几何预筛选**，只让通过筛选的结构继续跑较昂贵的 PDOS / Bader 计算，适合大批量初筛。
5. 确认无误后提交。

**预期结果**：生成一个新的批次，出现在批次列表中，可监控每个结构的进度。

### 7.2 监控与回收

**操作步骤**

1. 在批次列表中查看整体进度与各结构状态，点 **「↻ 刷新」** 更新。
2. 对运行中的批次可停止；对已失败的条目可查看原因。

## 9. 场景七：构建数据集与训练模型

### 13.1 机器学习 / 主动学习 CSV 导入：列角色自动识别

导入对话框支持「① 解析表头并确认列角色 → ② 导入」两步：选文件或粘贴 CSV 后先预览，系统自动判定每列角色，可手动改，或直接按自动识别导入。

| 列角色 | 自动识别示例表头 | 约束 / 说明 |
|---|---|---|
| **样本名**（必选一列） | `name` / `sample` / `material` / `system` / `体系` / `材料` / `id` | 文本列；未识别到时自动生成 `sample_0001…` |
| **目标 / 标签**（可选） | `target` / `label` / `eta` / `overpotential` / `η_OER` / `过电位` / `y` | 仅数值列；非数值文本列不可作目标 |
| **ε_d 特征列**（主动学习专用） | `ed` / `d_band_center` / `ε_d` / `d带中心` | 仅数值；含 η_OER 的行进训练集，仅含 ε_d 的行作候选集 |
| **特征列** | 其余数值列 | 自动作为特征；字符串会被忽略或报未知列 |
| **忽略列** | `note` / `source` / `comment` / `备注` | 自动忽略；可在预览中把任意列改为「忽略」 |

- 支持 UTF-8 BOM（Excel 直接另存）与千分位数字（`1,234.5`）；首行必须是表头。
- 高级：API 显式传 `mapping: {name_col, target_col, feature_cols:[...] 或 null, ed_col, exclude_cols:[...]}` 可覆盖自动识别；请求体带 `dry_run: true`（ML 与 AL 一致）只返回列判定、不落库，用于预览映射。
- 典型报错：`缺少 rows… 或 csv 文本`（两样都没给）、`CSV 解析失败: …`（表头重复/编码异常）、`mapping 中的列不存在: …`（列名拼写错误）。解析失败发生在写库前，不会产生脏数据；导入成功后按返回的 `imported` / `skipped` 计数核对。

## 14. 常见问题

**Q1：打开页面一直转圈 / 卡住？**
先刷新浏览器（F5）。若仍异常，可能是正在执行耗时操作，稍等后重试。持续异常请联系平台维护者（东翁 / 掌书）。

**Q2：某个列表一直是空的？**
说明该模块暂无数据，需先新增或导入。平台初始为空白状态，不会预置演示数据。

**Q3：操作时提示错误（如"缺少必填字段"）？**
按提示补全必填项后重试。这类提示属于参数校验，不是系统故障。

如果提示"存在无法识别的参数"，说明填写的参数名平台不认识——请对照提示中列出的合法参数名修改。**这类参数过去会被静默忽略并可能生成错误内容**，现在平台会明确拦截，请按提示修正。

**Q4：误删了内容，能恢复吗？**
平台没有回收站。**重要数据请定期自行导出留存**。若确需恢复，请联系东翁从备份中找回（平台每日会自动保留一份数据快照）。

**Q5：计算一直排队不开始？**
可能计算资源被其他任务占用。可在「计算任务」中查看当前运行中的任务数与资源占用；必要时停止不再需要的任务。

**Q6：账号密码忘记或提示权限不足怎么办？**
密码忘记请联系东翁（或获「账号管理」授权的掌书）在「平台设置 → 管理本地账号」中重置；提示权限不足说明当前身份无权执行该操作（清客/未授权掌书），不要反复重试。重置密码、停用账号或调整身份后，原会话会立即失效，需要重新登录。

**Q7：数据会上传到外网吗？**
平台的计算、结构解析、模型训练都在本地服务器完成。仅在你主动使用"联网检索文献"或"按 DOI 导入"时，才会向外部学术数据库发起查询；AI 助手的对话会发送给你配置的模型服务商。

**Q8：如何让助手帮我批量处理？**
开启「Agent 模式」后用自然语言描述任务；若涉及提交计算、写库等有实际影响的操作，还需东翁在服务端启用并勾选「⚠ 高权限工具」。

**Q9：图表能用于论文吗？**
可以。用各模块的「📈 下载图表」导出图片文件。

## 后处理工具集（2026-10-28）

侧栏「后处理工具集」提供差分电荷密度、Bader 结果导入/程序适配、PDOS 与计算输出审查。
选择工具后填写服务器文件路径；密度分析必须确认单位，Bader 导入还需确认原子顺序。
提交后在「任务与产物」查看进度、失败原因、检查结果，并下载结果 JSON、Δρ cube 或 PDOS CSV。
页面只在当前模块可见时轮询，顶部 CPU 卡片可查看分析进程资源。

Bader 原子盆计算需要管理员配置真实的 `CATMAT_BADER_BIN`，未配置时按钮禁用；已有
真实 ACF.dat 可先使用导入工具。参考电子数需逐原子填写并匹配密度/赝势定义，留空只显示
盆电子数。全空间差分密度积分不等于吸附物转移电荷，不能替代 Bader 或指定区域积分。

「执行完成」不是科学验收。所有新工具结果先作为预览，不自动进入训练数据集；已有
PDOS 的验收和入库仍在原计算任务入口进行。功函数、振动/Shermo、自由能、局域反应性
显示为规划中，尚不可运行。旧数据不会自动重算或改写。

导入数据集时的「立即训练」现为启动受控后台任务，使用本次新数据集；请到机器学习任务
列表查看结果。任意 Python 的在线结构执行暂未开放，请用结构生成表单或导入结构文件。

### 后处理工具的文件选择

后处理工具每个输入框均可点击「选择服务器文件/目录」浏览计算目录，选中后自动填入路径；PDOS 进入包含 `.pdos` 文件的目录后点击「使用当前目录」。选择窗口会保留主表单已有参数，也可继续手动填写服务器绝对路径。
