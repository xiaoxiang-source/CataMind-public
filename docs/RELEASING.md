# 源码发布说明

## 发布范围

`python3 scripts/prepare_release.py` 只读检查当前工作树中的明确文件清单；加 `--output <新目录>` 才会复制。输出目录必须不存在，避免覆盖旧发行包。源码包包含服务端、前端、全部 Python 工具、测试、示例种子及必要用户文档；不会复制 Git 历史。

部署目录中的数据库、备份、上传文件、研究数据、分析结果、日志、旧桌面二进制包和本机 Agent 指令仍保留原处，但不进入源码包。旧微信小程序为兼容实现，不属于本轮 Web 源码发行范围；后端微信开关默认关闭。桌面发行文件应单独作为 Release 附件管理。

排除清单由发布脚本负责；`.gitignore` 仅防止误添加，不能移除已经存在于历史中的内容。因此推荐从导出的干净目录新建 Git 仓库，而不是直接推送生产目录历史。发布脚本不会执行 git commit、push 或删除原文件。

## 验证

在导出的源码目录运行：

```bash
python3 scripts/check_release.py
python3 -m unittest tests.test_postprocess_http -v
```

回归不提交真实计算，不依赖生产数据库。NumPy 不可用时 PDOS 数值集成用例会标记 skipped；可设置 `CATMAT_TEST_SCIENCE_PY` 指向已安装 NumPy 的解释器再测。HTTP 用例启动本机随机端口测试服务，仅使用临时 SQLite 和临时输入。

`SOURCE_MANIFEST.json` 记录导出时的路径、字节数及 SHA-256。凭据扫描只匹配若干高置信格式，不能替代人工复核；检查文档、示例数据的公开授权，并确定根目录许可证之后再发布。导出包不含历史提交，未对原仓库全部历史做泄密结论。

## 本轮行为变化

- 外部计算程序默认路径以当前用户目录为基准，可用 `CATMAT_*` 显式覆盖；后处理额外根目录用冒号分隔的 `CATMAT_POSTPROCESS_ROOTS` 配置，空字符串关闭额外根目录。
- 增加 `CATMAT_DATA_DIR`、`CATMAT_CP2K_RUN_DIR`；不设置时保持原部署目录。配置新 data 目录后，需要种子数据时将已审阅的 `seed_*.json` 放入其中再使用 `--seed`。
- AiiDA 插件安装清单包含新增的三个根模块，避免迁移后漏装。
- 服务器执行助手及其共享文件改为仅管理员可访问；普通账号不再通过聊天通道获得服务器执行能力。
- 无鉴权服务拒绝绑定非回环地址。反向代理仍须由部署者显式启用鉴权与 TLS；回环地址本身不是代理访问控制。
- 健康接口增加 `postprocess_file_picker` 能力标记，便于区分新前端配旧后端的问题。

本轮不更改数据库 schema、不自动重启 Web/AiiDA、不重算历史研究结果。后端行为变化在下一次 Web 服务重启后生效。

## 发布副本脱敏

发布脚本默认对导出文本执行部署信息脱敏：移除实际备案编号，替换站点域名、个人 home 路径、内网地址及 systemd 用户名；首页不展示任何实际备案号，部署者自行配置。线上文件不被修改。清单哈希对应脱敏后的文件。数据库、账号与 Git 历史仍完全排除。模式检查无法证明不存在所有形式的个人信息，发布前仍应人工复核。
